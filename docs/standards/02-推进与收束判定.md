# 02 · 推进与收束判定

> 规则范围：DC-11 ~ DC-20 · 上级索引：[README](./README.md)
> 本份是整套标准的核心：**什么算「有推进」，什么时候必须停下来收。**

## 一、DC-11｜增量四类（Gain）

每次发言必须能归入至少一类增量，否则视为无效发言。

| 类型 | 含义 | 判据 |
|---|---|---|
| **E 新证据** | 带来场内此前没有的事实 | 有数据 / 查询结果 / 可核验来源；口头断言不算 |
| **A 新论点** | 提出未讨论过的机制、维度或解释 | 与已有发言不同构，不是换词复述 |
| **R 明确反对** | 指名反对某个具体观点并给出理由 | 有反对对象 + 有理由；「我觉得还要再看看」不算 |
| **C 新约束** | 引入口径、红线、资源、时间等硬约束 | 能改变可选方案集合 |

## 二、DC-12｜证据分级：C/D 级不能作为定案依据

增量 E 也分成色。定案只能建立在 A/B 级证据上。

| 级别 | 证据来源 | 可支撑 | 不可支撑 |
|---|---|---|---|
| **A 高置信** | 本场真实取数结果、官方看板、原始记录 | 事实层结论，可作为定案依据 | — |
| **B 中置信** | 跨场景重复出现的模式、历史多次验证的经验 | 判断层结论，需标注依据 | 单独作为精确数值结论 |
| **C 低置信** | 单次观察、类比推理、模型直觉 | 只能作为待验证方向，**必须标「推断」** | 定案依据 |
| **D 证据不足** | 无来源、无法核验 | 只能作为提问 | 任何结论 |

**硬约束**：收口产出里每条事实必须标级；C/D 级内容出现在 `facts[]` 即为违规，应改写为「待验证方向」并进入下一场输入。

**配套约束**（来自业务踩坑）：单个极端实验的结论属于 C 级——历史上「完全关闭列表页广告」的反转实验跑了 60 天，得出的兑换关系无法外推，最终必须靠「历史相关性 + 动态实验 + 分群曲线」三角验证。**单一来源的结论不许当 A 级用。**

## 三、DC-13｜纯附议不计增量，但计共识票

无新证据的 `support` 记 Gain=0，但在[共识分级](./03-收口与终止.md)里计一票赞同。它对收敛有用，对推进无用。

## 四、DC-14｜空轮定义

一轮结束时全部发言 Gain 合计为 0（全员 `pass`、纯附议、纯复述），该轮记为**空轮**。空轮是收束的输入信号，不是继续讨论的理由。

## 五、DC-15｜三问续议闸门（主闸）

每轮结束时主持人必须过一遍三问；**三问全为「是」才继续，任一为「否」立即前进**。

```
Q1 还有未决分歧吗？        （open contention 非空）
Q2 上一轮产生了增量吗？    （lastRoundGain > 0）
Q3 预算还够再判一次吗？    （轮次 / 步数 / token / 时长均未触顶）
```

**Q1 的补充判定（实测踩过的坑）**：「没有未决分歧」只有在**所有参会人都发过言之后**才成立。否则 Q1=否 只意味着「还没人说话」，会导致第一位专家发言后立刻收口，其余专家全程没上场。判定实现：`未发言人数 > 0` 时即使无分歧也返回 CONTINUE，并要求主持人优先点名还没发言的人。

判定伪代码（落点：`runRoundtable` 主持人轮末）：

```js
// 返回：CONTINUE | CONVERGE | ESCALATE | ACT | CLOSE_FORCED | ABORT
function decideNext(s) {
  if (s.redlineHit)                    return "ABORT";        // 红线 / 越权 / 依赖缺失
  if (s.openContention.length === 0)   return "CONVERGE";     // Q1 否：没分歧可议
  if (s.round >= MAX_ROUNDS ||
      s.budgetUsedRatio >= 1.0)        return "CLOSE_FORCED"; // Q3 否：预算耗尽，强制收口
  if (s.emptyRounds >= STALL_LIMIT)    return "CONVERGE";     // Q2 否：连续空轮 = 僵局
  if (!s.located && s.kind === "anomaly") return "ACT";       // DC-09：异常未定位，先取数
  const top = s.openContention[0];
  if (top.kind === "fact")             return "ACT";          // DC-16：查数裁决
  if (top.kind === "caliber")          return "ACT";          // DC-16：查口径真相源
  if (top.kind === "value")            return "ESCALATE";     // DC-16：升级决策人
  if (s.budgetUsedRatio >= 0.8)        return "CONVERGE";     // 留出收口余量
  return "CONTINUE";
}
```

`ACT` 与 `ESCALATE` 不是「继续讨论」，而是**离开讨论去解决**。用讨论替代动作是明确的反模式（[AP-06](./07-参数与反模式.md)）。

## 六、DC-16｜分歧三分法（最锋利的一条）

**每一条未决分歧必须先归类，再决定处置。分类错了，后面全错。**

| 分歧类型 | 特征 | 正确处置 | 常见错误处置 |
|---|---|---|---|
| **事实分歧（fact）** | 对「数据是多少 / 现象是否存在」看法不同 | **停止辩论，去查数**（`query`）。数据回来自动裁决 | 各自援引印象反复辩 |
| **口径分歧（caliber）** | 结论不同源于口径不同（时间窗 / 去重 / 分母 / 极值处理） | **停止辩论，查口径真相源**（`caliber_defaults.yaml`、官方看板）。规则说了算，一致性优先 | 争「谁的口径更合理」 |
| **价值分歧（value）** | 源于取舍偏好（做不做、优先级、能否接受风险） | **停止辩论，升级决策人**（`escalate`）。这类分歧不可能被数据消灭 | Agent 之间辩优先级；Twin 越权拍板 |

记住一句就够：

> **能被数据裁决的分歧，多辩一轮不如查一次；不能被数据裁决的分歧，辩一百轮也不会收敛。所以「继续辩论」的适用面比直觉窄得多——它只适合论点还没被摊出来的阶段。**

**口径分歧的补充规则**：口径不一致时以官方口径为准；确有差异时**量化差异并标注**，不允许「我这个口径也说得通」式并存。

## 七、DC-17｜五个收束触发器

命中任一即进入 P3 收束，不需要凑满。

| # | 触发器 | 判定 |
|---|---|---|
| CT1 | **可决** | 已达最小可决集（DC-19） |
| CT2 | **僵局** | 连续 `STALL_LIMIT`（默认 2）轮空轮 |
| CT3 | **场外** | 剩余分歧全为 `value` 类，或需要场内拿不到的外部信息 |
| CT4 | **预算** | 轮次 / 步数 / token / 时长任一到 80% 水位 |
| CT5 | **叫停** | 决策人要求收口，或主持人判定边际价值低于成本 |

## 八、DC-18｜倾向早收

判定模糊时选择收束。理由：收束产出物里带着「未决分歧 + 所需信息 + 重启条件 + 回看时间」，收早了可以按 [04](./04-重启与重议.md) 带触发器重开；而多辩的轮次是不可回收的成本。

## 九、DC-19｜最小可决集

「信息足够」不是感觉，是清单。**决策人做出这个决定所必需的最少信息**，默认四项（可按议题裁剪，裁剪须写明）：

1. **结论方向与量级**（是什么、多大）。
2. **该结论的证据与口径**（来源 + 口径 + 证据等级，见 DC-12，可核验）。
3. **主要反对意见及其未被排除的理由**（不是「有人反对」，而是「反对什么、为何不能排除」）。
4. **决策选项与各自代价**（至少两个可选项，含「不做」）。

四项齐 = 可决 = 必须收口。为「再充分一点」追加轮次，是对决策人时间的浪费。

## 十、DC-20｜升级时只问一个最小问题

升级给决策人（`escalate`）时：

| 要求 | 说明 |
|---|---|
| **一次只问一个** | 只问那个「不回答就无法继续」的问题。不一次抛多个非关键细节 |
| **带选项与代价** | 给至少两个可选项 + 各自代价，不要开放式提问 |
| **带默认建议** | 明确「如果你不回，我按 X 走」，并说明 X 的依据 |
| **可批量的不升级** | 低风险确认项按代答手册直接代答，事后在「我替你做的决定」清单里一次性呈现 |

**为什么单列一条**：多 Agent 系统最容易制造的伤害不是做错事，而是**把 AI 的产出速度直接转换成对人的打扰频率**。升级纪律是这套体系里对人最友好的一条规则。


## 标准 SOP（五阶段，每阶段之间必须用户确认）

### Phase 1 — 命题澄清（多轮对话）

**目标**：先弄清用户要分析什么，再动数据。一个合格的命题包含三要素：**观察 + 要回答的问题 + 决策目的**。

按以下顺序多轮交流，一问一答、每轮最多 1~2 个问题，不要一次性把 checklist 拍给用户：

1. **观察是什么**：用户看到了什么现象 / 收到了什么反馈 / 哪个指标在哪段时间发生了什么变化？
2. **要回答的问题**：找原因、验证假设、对比方案，还是例行复盘？
3. **决策目的**：分析结果会被谁在什么时候用来拍什么板（放量 / 回滚 / 调策略 / 立项）？
4. **已有线索**：用户有没有猜测、历史报告、关联实验 ID、版本 / 渠道变动？

当你能用**一句话复述命题**（例如「定位某指标近 14 天环比下跌 5% 的主因，用于是否回滚的决策」），把这句话给用户复核，等用户确认再进 Phase 2。

以下情况**不要前进**，回到 Phase 1 继续澄清：
- 用户给的是纯开放问题（"分析一下 DAU 最近怎么样"），缺时间窗 / 对标
- 观察本身没数据支撑（"感觉下跌了"但说不出幅度 / 时间）
- 决策目的不清（不知道分析出来要用来做什么）

用户若直接丢指标或 SQL 过来，也必须追问一句"这次分析想回答什么问题 / 要支持什么决策"，不能跳过 Phase 1。

---

### Phase 2 — 任务拆解

基于确认后的命题，把它拆解成**若干可独立查数的子任务**，每个子任务对应一条 SQL（或一条带 UNION ALL / CTE 的对照 SQL）。

**命题模板匹配**：先识别命题类型，命中下方「常见命题模板库」时**先套模板起草**拆解，再和用户对增删；命不中再从零拆。

给用户展示一份任务清单（markdown checklist），示例：

```
分析命题：定位某核心指标近 14 天环比下跌 5% 的主因

任务拆解：
[ ] T1. 主指标复核：近 14 天 vs 前 14 天，确认下跌幅度与口径一致
[ ] T2. 分维度拆解：按主要维度看哪几个贡献了下跌
[ ] T3. 分渠道拆解：各渠道谁在退
[ ] T4. 异常归因：定位异常点并给出归因结论
```

每个子任务必须打 1 个**范式 tag**（见 [analysis-paradigms.md](analysis-paradigms.md)）。

---

### Phase 3 — 逐子任务查数（SQL）

对每个子任务：

1. **写 SQL**：用真实表 / 列 / 口径写只读 SELECT。若不熟悉表结构，先查表结构再写。
2. **用户确认 SQL**：把 SQL 给用户看一眼（尤其涉及口径选择时），确认后执行。
3. **执行**：经数据查询适配器执行，拿到真实结果。
4. **速览**：给出数据速览（行数、关键数值、趋势方向），不做深度分析。

---

### Phase 4 — 分析与归因

按范式 tag 决定分析方法：

- **SQL-only 范式**（对比 / 拆解 / 漏斗）：Phase 3 的数据已够，直接做归因。
- **SQL+Python 范式**（波动 / 分布 / 趋势 / 留存 / 预测）：需要 Python 增强（STL / 变点 / 拟合 / 预测）。

**4d. 异常归因规则**：

| 条件 | 动作 |
|------|------|
| 同比 / 环比 \|Δ\| > 阈值（默认 15%） | 追加一轮下钻 |
| 下钻后仍无法解释 | 标注 `[未解释]`，不强行归因 |
| 多因素贡献 | 给出各因素贡献度排序 |

**4e. 预测置信规则**：

| 输出 | 必带字段 |
|------|----------|
| 点预测 | 置信区间 / 误差带 + 显式假设 + ≥2 条失效条件 |
| R²/MAPE 不达标 | 标注 `[低置信]` |

---

### Phase 5 — 报告交付

把分析结论汇总成结构化报告：

1. **标题**：一句话概括结论
2. **TL;DR**：3~5 行核心发现
3. **分节**：按范式 tag 决定 section 模板（见各范式文件的「Phase 5 报告必填 sections」）
4. **数据支撑**：每个结论附数据表 / 图表
5. **风险提示**：不确定项 / 假设条件 / 下一步建议

**交付前自检清单**：

- [ ] 每个结论都有数据支撑（非凭印象）
- [ ] 异常已归因或已标注 `[未解释]`
- [ ] 预测带置信信息
- [ ] 报告结构完整（标题 / TL;DR / 分节 / 数据 / 风险）
- [ ] 无编造数字
- [ ] 口径一致（同一指标前后口径相同）
- [ ] 时间窗明确

## 常见命题模板库

| 命题类型 | 范式组合 | 拆解模板 |
|----------|----------|----------|
| 指标异动归因 | 波动 → 拆解 → 对比 → 分布 | T1 复核 → T2 拆维度 → T3 对比 → T4 分布 |
| 新功能 launch review | 对比 → 漏斗 → 留存 → 分布 | T1 前后对比 → T2 漏斗 → T3 留存 → T4 副作用 |
| 灰度推全决策 | 对比 → 波动 → 预测 | T1 对比 → T2 波动 → T3 预测外推 |
| 季度冲刺评估 | 趋势 → 预测 | T1 趋势 → T2 预测 |
| 节假日影响预估 | 预测 + 波动 | T1 类比预测 + T2 波动 |
| 周报 / 例行复盘 | 对比 → 波动 → 趋势 → 分布 | T1~T4 全覆盖 |

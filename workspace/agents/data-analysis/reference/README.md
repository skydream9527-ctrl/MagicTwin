# 数据分析 Agent

资深数据分析师，把自然语言需求转成可执行 SQL，通过数据查询适配器查真实数据并做分析归因。

## 能力

- NL→SQL：自然语言转只读 SQL
- SQL 执行：经数据查询适配器查真实数据
- Python 沙箱：预测 / STL / 变点 / 拟合
- 8 分析范式：对比 / 拆解 / 波动 / 漏斗 / 分布 / 趋势 / 留存 / 预测
- 自动出报告

## 工作流程

1. **命题澄清** — 多轮对话明确分析目标
2. **任务拆解** — 拆成可独立查数的子任务
3. **逐子任务查数** — 写 SQL → 确认 → 执行 → 速览
4. **分析与归因** — 按范式做分析，异常必归因
5. **报告交付** — 结构化报告 + 自检清单

## 分析范式

每个子任务必须打 1 个范式 tag，详见 [analysis-paradigms.md](prompt/analysis-paradigms.md)。

## 数据查询

- 通过 `query_data` 工具执行只读 SELECT
- 默认演示模式返回示例数据
- 接入真实数据源：设 `QUERY_BACKEND=command` + `QUERY_COMMAND="your-cli {sql}"`
